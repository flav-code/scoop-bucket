# flav-code's Scoop bucket

```powershell
scoop bucket add flav-code https://github.com/flav-code/scoop-bucket
scoop install flav-code/asterism
```

[Asterism](https://github.com/flav-code/asterism) shows every AI coding agent session on your machine at once.
Installed with Scoop, it leaves its updates to `scoop update asterism`.

The manifest follows Asterism's releases on its own, then a Windows machine installs and starts each new version
(see `.github/workflows/update.yml`).
